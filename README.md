# PC Monitor

Десктопное приложение для мониторинга состояния компьютера (WPF, .NET 8, MVVM).
Учебный проект, дисциплина МДК.01.01.

## Статус
- Этап 3 — пользовательский интерфейс: готов.
- Этап 2 — реальный мониторинг CPU, RAM и дисков (`Services/SystemMetricsProvider.cs`): готов.
  Опрос выполняется в фоновом потоке. Права администратора не нужны.
- Страница «Система»: ядра/потоки CPU, тип/частота/модули RAM, модель, видеопамять и драйвер видеокарт (WMI + реестр, `Services/HardwareInfo.cs`).
- Этап 5 — GPU и температуры через LibreHardwareMonitor (`Services/HardwareSensors.cs`): нагрузка и видеопамять GPU,
  температура GPU и CPU. Датчики открываются в фоне за 1–3 с после запуска. Недоступный датчик показывается как «Недоступно».
  Температура CPU на большинстве систем читается только при запуске от имени администратора; остальное работает без прав.
- Этап 4 — история в SQLite (EF Core): `Data/`, `Services/HistoryRecorder.cs`. Файл базы: `%AppData%\PcMonitor\history.db`.
  Таблица `MetricsHistory` (Id, Timestamp — Unix-секунды UTC, MetricType, Value, DeviceName). Запись пакетами в фоне с заданным
  периодом, автоудаление записей старше срока хранения, досрочный сброс при выходе, ошибки БД показываются на странице «История».
  В режиме `--demo` история не пишется.

Демо-данные для разработки UI: запуск с ключом `--demo`.

## Запуск
Требуется Windows 10/11 и .NET 8 SDK.
```
dotnet restore
dotnet run --project PcMonitor.csproj
```

- Уведомления о превышении порогов (`Services/ThresholdNotifier.cs`, `NotificationService.cs`): всплывающее окно, звук (опционально),
  мигание кнопки на панели задач. По каждому показателю не чаще, чем раз в заданное число минут (ТЗ 4.1.11).
  Проверить внешний вид: Настройки → «Показать тестовое уведомление».

- Трей (`Services/TrayService.cs`): значок с меню «Открыть / Настройки / Выход», двойной щелчок открывает окно, подсказка с текущей
  загрузкой. Настройки «Приложение»: сворачивание в трей при закрытии/сворачивании, автозапуск (HKCU\\Run, ключ `--autostart`),
  запуск свёрнутым в трей (только при запуске системой). Всё выключено по умолчанию.
  Автозапуск «с правами администратора» — задача Планировщика Windows с наивысшими правами (запрос UAC один раз при сохранении
  настройки; дальше запуск без вопросов). Нужен для температуры CPU. Если экземпляр работает от администратора, а запущен ещё один
  обычный, он не создаёт дубль, а просит первый показать окно (`Services/WindowActivation.cs`). Второй экземпляр не запускается — он
  показывает уже работающее окно. Когда окно в трее, предупреждения приходят системными сообщениями у значка.

## Что есть в UI
- **Обзор** — карточки CPU, RAM, GPU, температуры, диски, общий график за минуту.
- **Графики** — выбор показателей и окна 60/120 с, подсказка при наведении.
- **История** — выбор периода и показателя, сводка (среднее/макс/мин).
- **Система** — сведения о компонентах.
- **Настройки** — тема, интервал 1–10 с, история и срок хранения, пороги и ограничение повторов уведомлений.
- 5 тем (Тёмная, Светлая, Океан, Фиолетовая, Изумруд); переключение без перезапуска — в Настройках или кнопкой в заголовке окна.
- Недоступные показатели отображаются как «Недоступно» (ТЗ 4.6.4); демо-режим GPU-температуры показывает это состояние.

## Структура
```
Themes/       словари цветов тем (одинаковый набор ключей)
Styles/       Base.xaml (стили контролов), Icons.xaml (иконки)
Controls/     LineChart (свой график), MetricCard, конвертеры
Models/       записи данных (MetricsSnapshot и др.)
Services/     IMetricsProvider, MonitoringService, ThemeService, SettingsService
ViewModels/   MVVM (CommunityToolkit.Mvvm)
Views/        страницы
```
Настройки хранятся в `%AppData%\PcMonitor\settings.json`.

## Добавить новую тему
Скопировать `Themes/Dark.xaml`, изменить цвета, добавить запись в `ThemeService.Themes`.
